# 地铁小测

一个中文的伦敦地铁小测。四条线，二十站，走完一条线停下来玩一个小游戏。

答题不是重点，游戏才是：**有些事读一句话没用，得自己做一遍。** 半克朗不是两先令半——这句话你现在就看懂了，但要真正记住，得在 1863 年的售票窗口后面数一遍零钱。

## 四条线

| 线 | 站数 | 走完之后 |
|---|---|---|
| 1 开端 | 5 | **售票窗口**，1863 |
| 2 工程 | 5 | — |
| 3 图纸 | 5 | **绘图室**，1931 |
| 4 运营 | 5 | — |

进度不画成进度条，画成**线路图**：一道题就是一站，答对填实，答错留空心环，走过的区间描上线路色。它同时说明你在第几站、哪几站答对了、离终点还有多远——换个题材就长不出这个东西。

### 售票窗口，1863

1863 年 1 月 10 日，大都会铁路通车第一天，Farringdon Street 的窗口。乘客把钱推过来，你从钱屉里拣零钱。

硬币按**真实直径**画。银三便士 16mm，比青铜法寻 20mm 还小，却值它十二倍——大小跟面值无关，看的是成色。这个荒谬讲不清楚，只能看。所以钱屉的格子不等宽：谁多宽由硬币自己定，塞进一样大的格子里，这一关的立论就没了。

末关跳到 1971 年 2 月 15 日，同一个窗口（这时它已经叫 Farringdon 了）。半克朗要换成新便士，四个答案都说得通，你得先决定按哪条规矩算。这一屏换成 British Rail 1965 年那套企业形象——铁路蓝、珠灰窗带、警示黄，因为 1971 年的车站就是那副样子。

£sd 算术是 [predecimal](https://github.com/sakulik2/predecimal)（MIT，本项目作者自己的库）的部分移植，用整数法寻记账，一镑 960 个。原库的断言全搬过来做了校验。

**第二遍玩不是同一道题再来一次。** 每位乘客有三套，按通关次数轮换——换的是买几张和递什么钱，票价一个字都不动，那是查过的史实。同时提示逐层收走：第二遍不再写明该找多少，第三遍还要求最少枚数。

两件都得做。只收提示，第二遍考的是记住那五个金额，不是做那道减法；只换内容，脚手架还在旁边撑着。所以 `check:tiers` 要求同一位乘客的三套金额互不相同。

拆提示不等于把人扔在那里：算不出来可以要提示，两步——先只说多了还是少了，再说差多少。而且第二遍起「交给乘客」不按金额禁用，因为按钮一亮就等于宣布算对了。你可以照交，乘客数完会推回来。

### 绘图室，1931

给你七个车站的真实地理坐标，重画成只有 0° 和 45° 的线路图。这是整个题材里最有名的一次设计行为，而且它真的是个谜题。

画完叠上代价：图上等长的两段，地面上差 2.8 倍。

## 跑起来

```bash
npm install     # yarn / pnpm install / bun install 都行
npm run dev
```

**Node 要 ≥ 22.6**，因为 `check:money` 直接跑 `.ts`，靠的是 Node 原生执行 TypeScript。这是唯一一条硬性要求，包管理器随便挑。

```bash
npm run build   # tsc -b && vite build
npm run check   # 类型 + 四个校验脚本，改完跑这个
```

调试不用从第一站走到底。地址栏加 `/test` 就有跳关索引：

| 写法 | 去处 |
|---|---|
| `#/test` | 索引页 |
| `#/test/3-02` | 3 号线第 2 站 |
| `#/test/1-x` | 1 号线走完的换乘页 |
| `#/test/ticket` | 售票窗口，1863 |
| `#/test/decimal` | 售票窗口，1971 |
| `#/test/drawing` | 绘图室 |
| `#/test/end` | 终点线网图 |

站号和界面上那块站号牌是同一套写法，看到什么码就能敲什么码。

## 这个库怎么组织

**一个 reducer 管全部状态**（`src/state/journey.ts`）。分数、每站对错、按钮文案、线路图上哪个点填实——**全都是推导出来的**。给其中任何一项加第二个真相来源都是 bug。

**题目是数据**，一条线一个 JSON，`src/data/lines/` 下面。加载时逐条校验，不对就抛错并指名是哪条线哪一站，而不是渲染出一个坏掉的车站。

**游戏挂在注册表上**。`GAMES` 把线号映射到游戏 id，加一个游戏就是加一条记录，不用改流程。

没有测试框架，改用**数据校验脚本**，每一个都是因为真的出过一次 bug 才写的：

- `check:lines` — 站名不能泄露自己那道题的答案。线路图从上车就显示全部站名，所以曾经有「波士顿」「布达」这种标签在题目读到之前就把答案说了。
- `check:money` — 36 条断言，来自 predecimal 原库和《1969 年十进制货币法》附表一。钱算错了，售票窗口就没有意义。
- `check:drawing` — 从坐标重算方位角和段长，还要求最长段至少是最短段的 1.5 倍，否则这一关没有可揭示的东西。
- `check:tiers` — 重玩难度。三档必须逐层收紧，拆掉提示的档必须有两级退路能把信息要回来，而且同一位乘客的三套应找金额不能相同——相同的话记住就行，等于没换。它当场抓出两处我肉眼漏掉的金额重复。

`src/game/drawing.json` 是生成的，别手改。

架构细节和惯例在 [CLAUDE.md](CLAUDE.md)，还没做的两个游戏在 [ROADMAP.md](ROADMAP.md)。

## 一点历史洁癖

**事实要先查证再写进数据，并且记下出处。** 会过期的说法（「世界最长」这类）不写，除非标了日期和来源。

有两个流传很广的说法查不到可靠来源——「泰晤士河是贝克唯一保留的地理要素」和「站距被画成均匀的」——所以文案里没有它们。

## 它原来是一个文件

这个项目最早是一个 1281 行的 HTML，双击就能打开。那是根提交，留在 `legacy` 分支上：

```bash
git show legacy:index.html > /tmp/metro-single.html
```

`main` 从它长出来——同一个 `index.html` 路径，单文件变成了 Vite 的入口。
